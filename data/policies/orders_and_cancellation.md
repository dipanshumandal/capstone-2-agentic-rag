# ShopEase Orders, Changes and Cancellation Policy

Last updated: September 2026

## Placing an order

Orders can be placed on the website www.shopease.com or the ShopEase mobile app. A customer account is needed for placing an order so the order history, invoices and refunds stay in one place. Guest checkout is not supported.

An order confirmation email and SMS are sent immediately with the order number. The order number is a 10 digit number starting with SE, for example SE12345678.

## Changing an order

Items in an order can be changed (size, colour, quantity) from My Orders > Modify Order only while the order status is "Processing", which is normally the first 2 hours after the order is placed. After the order is dispatched, changes are not possible. The customer can cancel the delivery when it arrives and place a new order instead.

## Cancelling an order

An order can be cancelled from My Orders > Cancel Order at any time before dispatch. There is no cancellation fee for orders cancelled before dispatch and the full amount is refunded.

If the order has already been dispatched the customer can still cancel it, but the delivery charge (if any) is not refunded and a cancellation fee of Rs. 50 is deducted for orders below Rs. 1000. For orders of Rs. 1000 or more the cancellation fee after dispatch is 5% of the order value, up to a maximum of Rs. 500.

Cancellation refunds are processed to the original payment method within 5 to 7 business days, or instantly to the ShopEase Wallet if the customer selects the wallet option.

## Order status

The order status values are: Processing, Packed, Dispatched, Out for delivery, Delivered, Cancelled, Returned. The current status is shown in My Orders and is updated by the courier partner.

## Invoices

A GST invoice is generated for every order once it is dispatched. It can be downloaded as a PDF from My Orders > Download Invoice. Invoices for the last 2 years are kept in the account. If a GST number has to be added to the invoice, it must be added in My Account > Business Details before placing the order, it cannot be added afterwards.
